# Не спи — Android

Невеликий застосунок для утримання екрана активним за явною командою користувача.

## Можливості
- Увімкнення та вимкнення режиму з головного екрана.
- Продовження роботи режиму, коли застосунок згорнуто, через foreground service.
- Постійне системне сповіщення з дією «Вимкнути».
- Збереження стану перемикача між відкриттями застосунку.

## Збірка
Android Gradle Plugin 8.7.3, Kotlin 2.0.21, compileSdk 35, minSdk 26.
Відкрийте кореневу папку в Android Studio, виконайте Gradle Sync та Build → Build APK(s).

## Примітки
Постійне утримання екрана збільшує витрати заряду та може нагрівати пристрій.
Android і прошивки виробників можуть обмежувати фонові служби. Перевірте роботу на цільовому телефоні.
Служба запускається лише після натискання користувачем кнопки «Увімкнути».
